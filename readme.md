# 烽烟

三国题材的身份卡牌对战游戏：网页联机，空位由电脑 AI 补齐，一个人也能开局。
牌名、牌效果与武将技能均为本项目原创设计。

## 运行

```bash
npm install
npm start          # 默认 http://localhost:3000 ，可用 PORT 环境变量修改
npm test           # AI 自对弈：5 人局、8 人局各 300 局，检查不崩溃、牌数守恒
```

打开网页 → 填昵称 → 创建 5 人局或 8 人局 → 把 4 位房间号发给朋友 → 房主点开始。
朋友要能访问到这台机器（同一局域网，或部署到公网服务器 / 内网穿透）。

## 模式

| 人数 | 主公 | 忠臣 | 反贼 | 内奸 |
|---|---|---|---|---|
| 5 人局 | 1 | 1 | 2 | 1 |
| 8 人局 | 1 | 2 | 4 | 1 |

- 主公与忠臣：消灭所有反贼和内奸。
- 反贼：击杀主公。
- 内奸：成为最后的幸存者（最后击杀主公）。
- 主公身份公开、体力上限 +1；其余身份阵亡时翻开。击杀反贼摸三张牌；主公误杀忠臣弃光手牌与装备。

## 结构

| 路径 | 内容 |
|---|---|
| `src/engine/game.js` | 规则引擎：回合阶段、出牌、响应链（破计可被破计）、判定、濒死求援、死亡与胜负、视角过滤 |
| `src/engine/cards.js` | 100 张牌的牌库定义 |
| `src/engine/heroes.js` | 20 名武将与技能；文件头注释列出了全部可挂载的时机 |
| `src/ai/ai.js` | 电脑 AI：只看自己视角，按公开的敌对/援助记录推测身份 |
| `src/server/server.js` | HTTP 静态页 + WebSocket 房间；服务器权威，断线重连，超时与掉线由 AI 托管 |
| `public/` | 浏览器端（无构建步骤的原生 JS） |
| `test/sim.js` | AI 自对弈冒烟测试 |

## 加一个武将

1. 在 `src/engine/heroes.js` 的 `SKILLS` 里写技能，挂到需要的时机上（如 `damaged`、`turnEnd`、`active`）。
2. 在 `HEROES` 里登记 `{ key, name, kingdom, hp, skills }`。
3. 跑 `npm test` 看有没有把引擎弄坏。

## 环境变量

- `PORT`：端口，默认 3000
- `AI_DELAY`：电脑每次行动的停顿毫秒数，默认 650
- `TURN_TIMEOUT`：真人每次操作的超时毫秒数，默认 45000，超时后由 AI 代打这一步
